# Customer Churn Prediction

## Project Overview

Customer Churn Prediction is a machine-learning project intended to estimate whether a customer is likely to stop using a service. The project includes a Flutter interface for entering customer details and requesting a churn prediction.

# Flutter Application
The Flutter interface groups customer inputs into sections:

The form includes a Predict Churn button to submit the entered customer information for prediction.

# How to Run the Flutter App

1  Install the Flutter SDK and configure your development environment.
2  Open a terminal in the Flutter project directory.
3  Install the project's dependencies:
flutter pub get

4  Check the project for issues:
   flutter analyze

5  Run the application on an emulator or connected device:
   flutter run


#####    For the application to function and enable the prediction of customer churn, you must download the machine learning project—which shares the same name as the application—and run it; instructions for doing so can be found in the repository on GitHub.
